Source

The contracts behind the testnetbeta, the security policy, and the specs, served from this site at commit a932fb2. Every deployed contract is cross-linked to its verified source on Arbiscan and Sourcify, which are independent of us.

Why this page

Open source means you can read what you interact with, and read it somewhere we do not control. The GitHub repository is temporarily unreachable while the account is under review, so the code is published here, and the verification links below go to third parties that hold the compiled bytecode and the matching source independently of both this site and GitHub.

Trust the chain, not the label. The addresses below are the same ones in the Docs address table. If a contract you are about to use is not in that table, it is not ours.

Verify a contract

  1. Open the Arbiscan link. The Contract tab shows the verified source and the compiler settings; Exact Match means the on-chain bytecode was rebuilt from that source.
  2. Open the Sourcify link for a second, independent match of the same address.
  3. Compare either with the file served here. They are the same code; if they ever differ, the chain is right and this page is stale.
