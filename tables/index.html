Arms at pick time, reveals the six one at a time at the spacing above — the on-stream drumroll — and closes the table when the sixth lands. Signs with this wallet, only ever arms, reveals or closes, and only when the contract already allows it. Keep the tab open; stop it any time.

VRF board. There are no secrets, so the passphrase is not used and there is no fallback lock — that second path was exactly what let a table's opener choose between two outcomes. Arm fires one Chainlink draw for the next segment; Lock 6 locks whatever has come back; Re-arm replaces a draw that never landed, and only an unfulfilled one — a landed draw is final for everyone, this wallet included. Auto-pilot paces the arms, since the arm is what starts each beat.

If a reveal is lost or late: forcing it needs no secret, but only works between ~13 minutes and ~51 minutes after arming. Past that the block hash is gone and the table has to be re-armed. (Those are L1 blocks — on Arbitrum block.number is the L1 number.)
